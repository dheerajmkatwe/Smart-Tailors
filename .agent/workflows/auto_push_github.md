# Auto Push to GitHub Rule

## IMPORTANT STANDING INSTRUCTION
After **every single code change** made to the Smart Tailors project, always run:

```
git add -A
git commit -m "<descriptive commit message>"
git push origin main
```

- This applies to ALL changes — bug fixes, new features, UI tweaks, config updates, everything.
- Do NOT wait for the user to say "push to GitHub" — just do it automatically after every edit.
- This rule applies in ALL conversations, including new chats.
- Repository: https://github.com/dheerajmkatwe/Smart-Tailors (branch: main)
